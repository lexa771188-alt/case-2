# Кейс № 2 - интерактивный счётчик

Счётчик изменяет значение с помощью кнопок «Плюс» и «Минус». Значение может
меняться от `-10` до `10`.

- при отрицательном числе фон зелёный;
- при нуле фон красный;
- при положительном числе фон жёлтый.

При достижении `10` кнопка «Плюс» блокируется, а при достижении `-10`
блокируется кнопка «Минус». Под кнопками появляется сообщение
«Вы достигли экстремального значения».

## Запуск

Откройте файл `index.html` в браузере.
